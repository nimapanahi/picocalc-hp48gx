# Security policy

Please do not attach calculator ROMs, saved calculator states, credentials, or
other private data to public issues.

For ordinary emulator bugs, open a GitHub issue with the firmware version and
reproduction steps. For a vulnerability that could affect the host computer,
PicoCalc firmware integrity, or repository release process, use GitHub's
private vulnerability reporting feature when it is available for this
repository.

Only the latest prerelease and the latest stable release are actively
maintained.
